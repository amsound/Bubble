Bubble's alerts, made native

Every question Bubble asks today, and what it becomes when the operating system draws it. The Mac pictures are real NSAlert windows captured on this Mac, in Light and Dark, with Bubble's icon. Windows would use the system TaskDialog: I can't render that here, so its column is a written spec.

Alerts can hold a title, a short message, up to three buttons (more on a Mac) and, on a Mac only, a few extra controls. Anything with a list or a form is a window or a panel, not an alert.

How it's built

  • All of the above use the same route: rfd's message dialog where it is enough (two or three buttons), and objc2-app-kit NSAlert / the Windows TaskDialog API directly where we need red buttons, checkboxes, command links or details.
  • On a Mac each alert can be a sheet attached to the window or a free-standing alert. You asked for centred, so free-standing.

After the alerts: Cart Setup

Cart Setup is the biggest window (waveform, trims, loop audition, fades, behaviour). It gets its own design pass next, for Mac and Windows, with the same question asked up front: which parts are the system's own controls and which are drawn by Bubble.
